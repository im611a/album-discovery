# RYM data import

## 何时触发

- 用户提供 RYM CSV、JSON 或其他离线数据文件，并明确要求导入时。
- 用户要求对已提供文件执行导入前 dry-run、幂等重放或冲突分析时。

## 何时不触发

- 未提供本地数据文件，或只讨论数据策略而未要求导入时不触发。
- 不用于获取、访问、抓取、登录或自动浏览 RYM，也不用于绕过访问限制。
- 不用于网易云目录采集、页面展示实现、开源仓库研究或通用质量检查。

## 执行步骤

1. 登记用户提供的数据来源说明、导入时间、文件格式、校验和与字段版本；不自行判断或证明文件的授权状态。
2. 只读校验输入，检查编码、必需字段、数值范围、多值字段和重复记录。
3. 按 `RYM_TAXONOMY.md` 规范化评分、评分人数、Primary Genres、Secondary Genres 和 Descriptors。
4. 使用标题、艺术家、发行信息等稳定字段进行候选匹配，计算并记录置信度。
5. 先执行 dry-run，输出预计新增、更新、跳过、拒绝和冲突记录，不写入正式结果。
6. 仅在用户要求实际导入且 dry-run 可接受时执行幂等导入；使用稳定记录键和批次信息避免重复写入。
7. 生成冲突报告，保留原始值、规范化值、匹配依据、导入时间和批次结果。

## 安全边界

- 只处理用户在当前任务中提供的本地文件，不发起任何 RYM 网络请求。
- 不负责获取或抓取数据，不登录 RYM，不绕过反自动化或访问限制。
- 不要求 Skill 自行判断或证明文件授权状态，但必须记录用户提供的来源说明和实际导入时间。
- 不把缺失值推断成 0，不伪造评分、人数、流派或 descriptors。
- 不因匹配失败而覆盖既有高置信度数据；不把 RYM 用作收听或曲目来源。

## 输出要求

- 输出来源说明、导入时间、校验和、解析数、新增数、更新数、跳过数、拒绝数和冲突数。
- 明确标记 dry-run 或实际导入，并输出匹配规则、置信度分布、冲突原因和需人工复核列表。
- 每个发布字段都必须可追溯到输入记录与导入批次。
