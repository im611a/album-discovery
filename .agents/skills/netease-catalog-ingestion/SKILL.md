# NetEase catalog ingestion

## 何时触发

- 后续阶段明确要求实现网易云专辑目录采集、增量同步或字段映射时。
- 需要处理网易云专辑 ID、艺术家、曲目、封面、发行日期或官方收听链接时。
- 需要处理新发行 `ALL`、`ZH`、`EA`、`JP`、`KR` 市场频道的发现记录时。
- 需要设计可重试、可审计、不会让前台实时依赖上游的同步任务时。

## 何时不触发

- 单纯修改产品文档、页面代码或公开仓库研究不触发真实采集流程。
- 未明确授权真实网易云请求时不触发。
- RYM 评分与分类导入、UI 开发、通用质量检查分别由其他 Skill 负责。
- 不用于用户登录、播放代理、歌词、评论、歌单或个性化推荐。

## 执行步骤

1. 确认当前阶段允许联网，并复核 0.15A/0.15B 报告的证据与限制。
2. 定义批次、速率、超时、重试上限、缓存和停止条件。
3. 从获准的发现入口收集专辑 ID，再获取专辑详情和曲目；保留原始响应摘要与采集时间。
4. 规范化专辑、艺术家、曲目、封面和唯一网易云收听链接，保留上游 ID；地区与语言缺失时保持为空。
5. 将 `source_market_channel`、`source_list_endpoint`、`discovered_at` 写入来源或同步记录；同一专辑允许关联多个频道发现记录。
6. 以幂等方式写入暂存层，记录字段级来源、失败原因和最后成功时间。
7. 对重复、下架、空封面、曲目变化和来源频道变化执行校验，生成批次报告。
8. 只有在质量门通过后才发布供前台读取的本地快照。

## 安全边界

- 默认禁止真实请求；必须由当前任务明确授权，且不得越过阶段门。
- 不收集用户凭据，不在仓库写入 Cookie，不绕过验证码、风控、付费或地区限制。
- 仅服务器端批处理；浏览器和页面不得直接请求网易云。
- `ALL`、`ZH`、`EA`、`JP`、`KR` 只表示新发行请求侧市场频道，不得转换为专辑或艺术家的国籍、法域、语言或正式地区。
- 不根据名字、文字、搜索排序或频道成员关系猜测国家、地区、国籍或语言。
- 尊重适用条款、robots/访问政策、限流和删除要求；异常升高时立即停止。
- 网易云只作为目录、封面、曲目和外部收听入口，不代理音频。

## 输出要求

- 输出批次 ID、时间范围、请求与成功数量、失败分类、重试情况和停止原因。
- 输出字段映射、来源记录、发现频道上下文、数据质量统计及未解决风险。
- 明确区分专辑固有字段与来源发现上下文；不得输出未经可靠来源确认的地区或语言值。
- 禁止声称全量、稳定或无需登录，除非有可复现的已授权验证证据。
