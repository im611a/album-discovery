# Minimal album UI

## 何时触发

- 明确要求实现或调整首页、专辑卡片、专辑详情页或其响应式状态时。
- 明确要求实现发现专辑、新发行或搜索页面时。
- 需要把已批准的数据契约映射为 shadcn/ui 风格的最小组件时。
- 需要为这些 UI 行为补充组件测试时。

## 何时不触发

- 文档决策阶段、可行性验证或仅做数据源研究时不触发页面实现。
- 不用于网易云/RYM 采集、数据库设计、开源审计或仓库质量门。
- 不用于登录、评论、收藏、用户评分、在线播放或推荐曲目。

## 执行步骤

1. 阅读产品规格、信息架构和数据契约，确认本次获准的页面范围与本地快照字段。
2. 使用本地 fixture、服务端数据接口或已发布快照；定义加载、空、错误和缺图状态。
3. 优先组合小型语义组件，仅按实际需要添加 shadcn/ui 组件。
4. 实现键盘可用、语义标题、可辨焦点、合适替代文本和响应式布局。
5. 主导航仅使用首页、发现专辑、新发行、搜索；首页只呈现近期发行、高分专辑、最近收录、随机发现。
6. 发现页只提供获准的年份、年代、发行类型和 RYM 分类筛选；新发行频道必须标注为网易云市场频道。
7. 隐藏未经可靠来源确认的国家、地区、国籍和语言；详情页不放推荐曲目。
8. 添加针对关键文案、链接和状态的测试，再交给 `quality-gate` 验证。
9. 全站视觉改造先建立页面原型和运动等级；工具页保留清晰线性操作，沉浸动效只用于
   已获准页面。
10. 新客户端边界必须说明必要性，并验证不会改变查询参数、本机状态或服务端静态输出。

## 安全边界

- UI 不得实时调用网易云或 RYM，也不得接触 Cookie、凭据或抓取逻辑。
- 唯一播放行为是跳转网易云官方专辑入口；不嵌入或代理音频。
- 不擅自增加用户系统、社交、热度、追踪或下一阶段功能。
- 不创建国内/国外专区，不把“华语/海外”用于全站历史专辑；市场频道筛选只属于新发行列表。
- 不批量安装未使用的组件或复制完整设计系统。

## 输出要求

- 列出新增/修改组件、路由、数据依赖和覆盖的状态。
- 提供可访问性与响应式检查结果以及相关测试结果。
- 明确说明未实现的范围，并标出任何数据契约缺口。
