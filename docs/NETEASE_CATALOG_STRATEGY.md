# 网易云专辑目录策略

状态：阶段 0.16 正式策略；基于 0.15A/0.15B 小规模实验收敛，尚未进入正式接入。

## 目标与边界

网易云音乐承担第一版的专辑目录、封面、曲目和唯一外部收听入口。目录流程
未来应由受控服务器端批处理运行，生成本站可独立读取的发布快照。前台永远
不在页面请求期间回源。

该流程不采集评论、歌词、播放量、榜单热度、用户歌单或社交数据，也不代理
音频。RYM 的评分和分类字段不由网易云补齐。

## 已验证边界

0.15A 证明核心专辑元数据匿名访问基本可行，17/18 个样本完成标准化；0.15B 证明
专辑详情、专辑搜索、艺术家搜索和艺术家详情没有可靠地区或语种字段。详细证据见
`NETEASE_FEASIBILITY_REPORT.md` 和 `NETEASE_REGION_TAXONOMY_REPORT.md`。

因此网易云继续作为专辑目录候选来源，但不作为国家、地区、艺术家国籍或语言来源。
`ZH`、`EA`、`JP`、`KR` 只作为新发行请求侧市场频道，不能用于全站历史专辑分类。

## 获准后的发现入口

0.15 已对以下接口类别形成小规模证据，正式实现仍需后续阶段单独授权：

- 新发行/新碟列表，用于形成时间窗口内的候选专辑；
- 专辑搜索，用于补录已知标题和处理覆盖缺口；
- 艺术家专辑列表，用于扩充已收录艺术家的目录；
- 专辑详情与曲目详情，用于完成单张专辑记录。

实验成功不证明接口获得长期稳定性承诺、允许生产批量使用或适合全量采集。验证
边界见 `NETEASE_FEASIBILITY_PLAN.md`。

## 未来采集流程

1. 以明确时间窗和分页上限运行发现任务，记录候选网易云专辑 ID；新发行发现同时
   记录请求频道和列表端点，但不把频道写成专辑地区。
2. 对新 ID 或已到刷新期限的 ID 获取专辑详情，并提取艺术家、发行日期、
   封面和曲目引用。
3. 在需要且获准时批量补充曲目详情；不请求音频 URL。
4. 规范化字段并写入暂存批次，保留上游 ID、原始值摘要和采集时间。
5. 校验曲序、重复版本、缺失封面、下架与响应结构变化。
6. 只有通过质量门的记录才进入不可变发布快照。

流程必须幂等：同一网易云专辑 ID 的重复采集更新当前事实，不创建无依据的
重复专辑；不同版本是否合并由版本信息和人工规则决定。

## 核心字段映射

| 本站字段 | 网易云职责 | 校验 |
| --- | --- | --- |
| `neteaseAlbumId` | 唯一上游标识 | 必须存在且保持字符串精度 |
| 标题与别名 | 专辑展示身份 | 保留原文，另存搜索规范化值 |
| 艺术家 | 展示及匹配 | 保留网易云 ID、名称和顺序 |
| 发行日期 | 近期发行依据 | 保留原精度，未知部分不得臆造 |
| 封面引用 | 列表与详情封面 | 记录源 URL/资源标识和更新时间 |
| 曲目 | 详情页曲目表 | 按碟号、曲序稳定排序，不含音频地址 |
| 网易云专辑链接 | 唯一收听入口 | 按 0.15A 验证的模板生成并持续校验 |
| 首次收录时间 | 最近收录依据 | 由本站首次成功批次生成，不取自上游 |

国家、地区、艺术家国籍和语言不在第一版映射中。缺失时保持为空，不能根据名字、
文字、搜索顺序或市场频道补造。

## 新发行市场频道上下文

新发行同步允许使用 `ALL`、`ZH`、`EA`、`JP`、`KR`，并在来源记录保存：

- `source_market_channel`：本次发现使用的频道；
- `source_list_endpoint`：发现列表端点或其稳定标识；
- `discovered_at`：发现时间。

`source_market_channel` 是来源上下文，不是专辑固有属性。同一专辑可能从多个频道被
发现，应保留多条发现关系，不能覆盖成单一“地区”。前台只有新发行列表可以把这些
值显示为明确标注来源的临时频道筛选。

## 刷新与覆盖思路

- 新发行窗口可以较短周期刷新；稳定历史专辑使用更长周期。
- 下架、空响应和临时错误先标记，不立即删除已发布记录。
- 封面或曲目变化需要生成差异，超过阈值时进入人工复核。
- 目录覆盖率以可解释的发现入口计算，不声称覆盖网易云全部专辑。

具体周期、页数和阈值仍需在后续独立阶段以更长时间和更多样本确定。

## 账号与 Cookie 策略

0.15A 的小规模路径未使用登录、Cookie 或凭据，但这不证明生产访问方式已经获得
长期保证。项目不采集用户账号，不保存个人 Cookie，也不把登录流程当作目录基础
设施。如果后续核心目录必须依赖个人账号、扫码登录、验证码或高风险 Cookie，应
停止实现并重新决策，而不是绕过限制。

## 主要风险

- 非官方接口、加密参数或响应结构随上游客户端变化；
- 匿名能力、区域可用性、限流和封禁策略不透明；
- 封面授权、缓存期限、服务条款和批量访问边界需要独立复核；
- 专辑版本、合作艺术家、发行日期精度和曲目顺序可能不一致；
- 单一目录源故障会影响更新，但不得在前台实时切换到其他正式来源。

## 当前禁止事项

阶段 0.16 不得发起新的网易云请求、实现正式 Provider、写入 Cookie、安装代理或
解锁工具、生成音频链接、接入数据库或把实验结论外推为生产可用性。
