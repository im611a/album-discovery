# 专辑探索系统

## 相似专辑

相似算法位于 `src/catalog/exploration.ts`，只读取轻量发布索引，确定性计算：

| 贡献 | 权重 |
|---|---:|
| 共享核心流派 | 8 |
| 共享可靠相关流派 | 6 |
| 同一或相邻年代 | 3 |
| 共享本站聆听场景 | 2 |
| 相同发行类型 | 1 |

候选至少共享核心或可靠相关流派。算法排除当前专辑和本机“不感兴趣”记录；默认排除同艺人，数据不足时最多补一张同艺人专辑。前六项限制同一艺人最多一张、同一首要核心流派最多三张。RYM 评分、Descriptors、热度、音频特征和网络数据都不参与相似度。

每条理由来自实际贡献，优先说明共享相关流派，其次共享核心流派；不显示百分比、AI 判断或流行度。详情页在曲目后显示 4–6 项，合理候选不足时减少数量或隐藏。

## 探索路径

`/explore/` 支持：

- `?mode=genre&value=dream-pop`：核心流派或实际存在的可靠相关流派；
- `?mode=decade&value=2000s`：实际存在的发行年代；
- `?mode=scene&value=night`：本站策展聆听场景；
- `?mode=artist&value=<artistId>`：基于共享核心流派的艺人接力；
- `?mode=random&seed=12345`：FNV-1a 风格稳定哈希选择。

URL 只保存公开探索模式、稳定分类值、artistId 或 seed，不保存本机“不感兴趣”ID。相同目录与 seed 产生相同结果；无效参数安全回退到可用默认值。所有模式均不发起运行时 Provider 请求。

## 已知限制

相关流派只覆盖 11 张专辑，因此多数相似关系主要由人工核心流派建立。艺人接力当前没有合作关系图，只使用专辑主艺人身份与共享核心流派。随机 seed 用于可复现分享，不是密码学随机。
