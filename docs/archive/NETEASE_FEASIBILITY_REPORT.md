# 网易云专辑目录最小可行性报告（0.15A）

## 结论摘要

核心专辑元数据匿名访问基本可行。本次 17/18 个样本标准化成功；地区和语种字段
覆盖率均为 0%。网易云目前可以作为专辑目录候选来源，但不能直接作为地区字段
来源。匿名专辑搜索标记为 `PARTIAL`，是因为 18/18 次搜索请求本身均成功，但其中
`A Star Is Born Soundtrack`（Lady Gaga / Bradley Cooper，2018）没有达到本地
候选消歧的可靠匹配阈值，因此未能标准化。

本次小规模实验支持网易云**有条件继续作为主要专辑目录候选来源**：匿名状态下，
专辑搜索、专辑详情、艺术家专辑、新发行列表、封面 URL、发行日期、艺术家与 ID、
专辑类型、发行公司、曲目表和专辑页链接均获得了可用证据。

这个结论不等于生产接入批准。接口未返回足以可靠区分中国大陆、香港、台湾、
日本、韩国和欧美的逐专辑地区字段；语言字段同样缺失。访问方式依赖未承诺稳定性的
网页内部接口，且适用条款、目录及封面再利用权、长期稳定性和大规模访问边界尚未
完成评估。地区不能由名字、文字、语言或搜索排序猜测，后续必须使用独立、可审计的
权威映射，或者将地区保留为空。

当前不能据此宣布该访问方式适合长期、大规模或生产使用。

0.15B 已补充验证地区与市场信号，详见
[NETEASE_REGION_TAXONOMY_REPORT.md](./NETEASE_REGION_TAXONOMY_REPORT.md)。补充结果没有
改变核心目录匿名访问的初步可行性，但进一步确认：专辑和艺术家响应没有直接地区或
语种字段；`ZH`、`EA`、`JP`、`KR` 只能作为新发行请求侧市场频道，不能解释为国籍、
法域或历史专辑分类。

## 2. 访问方式与安全边界

实际方式是使用 Node.js 内置 `fetch`，直接匿名请求 `music.163.com` 的公开网页元数据
接口：专辑搜索、专辑详情、艺术家专辑列表和新发行专辑列表。所有请求串行执行，
每次请求完成后至少等待 2 秒；上限为 60 次。本次没有重试。

已确认：

- 未登录，未使用账号、手机号、二维码或验证码。
- 未读取或提交 Cookie、Token、Authorization 或其他个人凭据。
- 未设置自定义请求头，未读取浏览器数据，未使用代理或 IP 轮换。
- 未请求播放或下载地址、付费内容、用户数据、歌单、评论或播放记录。
- 未运行、安装或启动第三方网易云 API 项目。
- 请求日志不含请求头、响应头、Cookie、原始响应体或敏感令牌。
- 唯一实际访问的域名是 `music.163.com`。详情响应给出了 `music.126.net` 封面
  URL，但本次没有下载这些图像，也没有访问该域名。

## 7. 地区与语种验证

地区证据按以下规则判定：

- **direct**：专辑响应直接返回语义明确的地区字段。本次为 0/17。
- **inferred**：新发行接口接受 `ZH`、`EA`、`JP`、`KR` 等频道参数，因此可把返回项
  视作某个频道中的候选，但频道含义和逐专辑国籍不是同一件事。
- **unavailable**：专辑详情没有足够的明确字段。本次 17/17 属于此类。

接口没有给出可用于可靠区分中国大陆、香港、台湾、日本、韩国和欧美的逐专辑直接
地区字段，也没有返回可用的语言字段。不能依据中文字符、艺术家名字、专辑语言或
搜索排序补写地区。新发行频道最多提供弱的候选分组，不能直接落为专辑国籍。

## 8. 风险与适用规则

- **平台与法律风险**：本实验没有确认网页内部接口是否允许被本项目持续调用，也
  没有确认专辑元数据、曲目数据和封面 URL 的缓存、展示、再分发边界。本报告不是
  法律意见；生产决策前需要审阅届时有效的服务条款、robots/开发者规则和权利范围。
- **稳定性风险**：接口路径和响应结构可能在无通知时变化，匿名可用性也可能受
  网络、地区和风控策略影响。
- **匹配风险**：同名专辑、多艺术家、原声、豪华版、重制版和再发行版本需要明确
  的候选评分、dry-run 与人工冲突队列。
- **完整性风险**：公司字段有缺失，别名覆盖很低，地区和语种完全不可用；曲目数
  还可能受附赠曲、伴奏、合并长轨和多碟结构影响。
- **封面风险**：本次只取得封面 URL，没有下载文件，也没有验证热链、缓存许可、
  尺寸变体、失效策略或 CDN 稳定性。
- **规模风险**：未验证分页上限、全量遍历、增量同步、重复数据、删除/下架、速率
  上限、缓存命中或持续运行。

## 9. 建议与决策门

建议保留“网易云是专辑目录、封面、曲目和唯一收听入口的主要来源”这一产品方向，
但只作为**有条件候选**，尚不进入正式数据接入：

1. 在任何生产实现前，确认适用条款、允许的访问方式、缓存与封面展示边界。
2. 将地区/语种从网易云目录能力中剥离；没有可靠来源时保留为空。
3. 为同名、多艺术家、原声和版本差异设计可审计的匹配分数与人工冲突流程。
4. 如获继续授权，再用独立阶段验证分页、增量、重复/下架、响应结构变化和更长时间
   的低频稳定性；不得从本次实验自动进入数据库或正式 Provider 实现。

如果合规评估要求账号、Cookie、验证码、绕过限制、非公开服务或不可接受的反向工程
维护，本项目应停止该路线并回到数据源决策，而不是规避限制。

## 10. 尚未验证的事项

- 生产用途是否符合届时有效的平台规则、合同与权利要求。
- 官方或受支持的长期访问方式，以及接口结构的版本承诺。
- 分页、全目录覆盖、增量更新、删除/下架、重复版本和 ID 迁移。
- 60 次以上、跨时段、跨网络区域的稳定性和速率限制。
- 封面文件下载、热链、缓存、尺寸、失效和再利用许可。
- 专辑页链接的逐一浏览器跳转和地区可见性。
- 语言、国家/地区、版权地域和发行市场的权威字段来源。
- 搜索消歧在更大规模同名、多艺术家、原声、重制版样本上的准确率。
- 正式存储模型、数据库、队列、计划任务、监控、部署和前台集成。
- RYM 数据导入、匹配和任何在线获取；本阶段未触及 RYM。
