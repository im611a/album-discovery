# RYM 离线导入策略

状态：阶段 0.1 设计；当前没有访问或抓取 RYM。

## 数据职责

RYM 只提供以下正式丰富字段：

- 评分；
- 评分人数；
- Primary Genres；
- Secondary Genres；
- Descriptors。

专辑目录、封面、曲目和收听入口仍由网易云音乐提供。RYM 不作为播放、目录
发现或曲目来源。

## 可接受输入

导入只接受当前任务明确授权的离线数据文件，例如合法导出、获许可数据集或
经过人工整理且能说明来源的文件。每个输入必须登记：

- 来源与允许用途；
- 生成日期和数据覆盖范围；
- 文件格式、字段版本和编码；
- 内容校验和；
- 提供者及任何保留/删除要求。

来源不清、授权不清或依赖实时网页抓取的输入不得进入导入流程。

## 导入阶段

1. **登记**：生成导入批次，记录文件元数据和校验和。
2. **解析**：以只读方式验证行结构、编码、多值字段和数值范围。
3. **规范化**：按 `RYM_TAXONOMY.md` 保留原始标签并生成比较用规范化值。
4. **候选匹配**：使用标题、主要艺术家、发行年份和版本提示寻找网易云目录
   中的候选专辑。
5. **决策**：高置信度唯一候选可接受；多候选、版本冲突和字段不足进入复核。
6. **暂存**：写入原始值、规范化值、匹配证据和批次，不直接覆盖发布快照。
7. **质量门**：检查覆盖率、拒绝率、异常评分、标签分布和来源完整性。
8. **发布**：通过后生成新的不可变读快照，支持按批次回滚。

## 匹配原则

匹配不是仅按标题的字符串连接：

- 比较时可折叠大小写、空白和常见标点，但保留展示原文；
- 艺术家必须参与判断，并处理合作署名和 Various Artists；
- 发行年份用于缩小候选，不单独决定版本；
- deluxe、remaster、expanded、live 等版本标记必须保留并进入冲突判断；
- 低置信度不得自动接受，也不得用另一个高分版本覆盖目标版本。

匹配阈值需要在获得合法样本后根据误配成本确定。

## 更新与冲突

- 每次导入生成新快照，评分和评分人数必须来自同一输入时点。
- 标签变化保留前后差异，不静默合并 Primary 与 Secondary。
- 同一文件重复导入应产生相同规范化结果，不重复创建丰富记录。
- 新批次质量显著下降时保持旧发布快照，并输出阻断报告。

## 数据质量检查

- 评分必须在输入定义的合法范围内；缺失不是 0。
- 评分人数必须为非负整数，并与评分共同有来源。
- 三类标签字段均为有序、去除完全重复项后的列表。
- 每条接受记录必须有专辑匹配依据、置信度和批次。
- 报告解析数、接受数、拒绝数、冲突数、覆盖率与人工复核数。

## 安全与合规边界

- 不登录 RYM、不自动浏览、不抓取页面、不绕过反自动化或访问控制。
- 不把输入文件提交到仓库，除非许可明确且任务单独授权。
- 不在日志中复制整份原始数据；样例应最小化并可脱敏。
- 如许可限制与产品使用冲突，停止导入并保留证据，不寻找技术绕过。

## 当前结论

只有策略和字段契约已经确定；没有真实 RYM 文件、导入实现或抓取结果。
