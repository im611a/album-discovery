## 4. 当前数据流

1. **首页**：`src/data/albums.mock.ts` → `src/lib/albums.ts` 的三个排序函数 → `src/app/page.tsx` 切片 → `AlbumGrid` / `RandomDiscovery`。
2. **发现页**：`albumsMock` → `buildDiscoverOptions` 和 `parseDiscoverQuery` → `filterAndSortAlbums` → `DiscoverCatalog` → `AlbumGrid`。
3. **新发行**：`newReleaseSourceContextMock` 以 `albumId` 关联 `albumsMock`；`selectNewReleaseAlbums` 先按频道选择来源记录、以 Set 去重专辑 ID、再按发行类型过滤和按日期/标题稳定排序。
4. **详情**：路由 slug → `getAlbumDetailBySlug` 查找 `albumsMock` → `albumId` 查找 `albumDetailsMock` → `AlbumDetail`。
5. **详情链接**：`AlbumCard` 整卡链接到 `/albums/${album.slug}`；首页、发现、新发行通过同一 `AlbumGrid` 获得一致行为。
6. **分类链接**：AlbumDetail 调用 `getDiscoverTaxonomyHref`，把来源标签转换为发现页稳定参数，再由 `getDisplayLabel` 只改变显示文字。
7. **URL 读取**：DiscoverCatalog 和 NewReleasesCatalog 都使用 `useSearchParams()` 读取；纯函数负责验证无效参数并回退默认值。
8. **URL 写入**：两个客户端目录都用序列化函数生成查询字符串，再调用 `router.push(..., { scroll: false })`。
9. **刷新与前进后退**：状态不是另存到全局 store，而是每次从 `searchParams` 重新派生；刷新和 history 导航依赖 Next.js 更新 `useSearchParams()`。
10. **搜索可复用基础**：`albumsMock`、`formatArtists`、AlbumGrid、AlbumCard 和详情 slug 可以直接复用；当前没有搜索匹配或排名纯函数。

这些前端 Mock 类型只用于 v0.2 UI 契约验证。`MockAlbum.artists`、`cover`、`addedAt`、`neteaseUrl` 等便利字段不得被描述为 v0.3 的最终数据库字段或物理表设计。

## 5. 当前复用关系

- **AlbumCard**：通过 AlbumGrid 同时服务首页、发现、新发行；搜索必须继续复用。
- **AlbumGrid**：`layout="home"` 为 2/3/6 列，默认目录布局为 2/4/6 列；搜索使用默认布局。
- **AlbumCover**：卡片、随机发现和详情共用；详情只通过 `size="detail"` 增加尺寸类。
- **SiteHeader / SiteFooter**：全部主要页面、占位页和 404 共用，没有重复页头或页脚 JSX。
- **display labels**：卡片、筛选、随机发现、详情共用同一 `getDisplayLabel`，未知值回退来源原文。
- **URL 参数模式**：发现和新发行都采用“纯解析/序列化函数 + 客户端 `useSearchParams` + `router.push`”；搜索应沿用模式但使用独立 `q` 契约。
- **空状态**：发现与新发行各自拥有相似但不完全相同的 JSX 和 CSS；目前没有共享 EmptyState 组件。
- **纯函数**：发现筛选/排序、新发行去重/排序、详情查询/格式化已从 JSX 分离；搜索必须先补纯函数，再写页面交互。

不得再创建第二套 AlbumCard、AlbumGrid、AlbumCover、TrackList、显示名称映射、专辑 Mock 数据或详情 slug 路由。当前不应为了消除两段小型 URL 导航样板就引入状态管理框架；是否抽取共享 URL helper 必须以真实重复收益和测试复杂度为依据。

### 样式系统事实

- 设计变量全部从 `src/app/globals.css` 的 `:root` 进入：页面背景 `#060a12`、次级背景/表面 `#0a111e`、卡片 `#0d1726`、overlay `#111d2e`、主文字 `#f4f7fb`、辅助文字 `#9bafc5`、边框 `#1b2b42`、强调与 focus `#70b7ff`。
- 页面最大宽度由 `.page-container` 统一为 1240px；手机两侧总留白 32px，640px 起为 48px。
- 圆角 token 为 6px 和 10px；标题字号由各页面现有 `clamp()` 控制。没有独立 typography 配置文件。
- 手机页头采用两行 grid；760px 起为 brand/nav/search 单行。主导航 active 使用 `aria-current` 与共享背景/文字状态，search entry 同样处理。
- AlbumGrid 手机 2 列，640px 起目录 4 列、首页 3 列，1120px 起两者 6 列。搜索可直接使用目录规则。
- 详情封面手机为可用宽度 86%、最大 310px；640px 起进入两列 hero 并最大 420px。AlbumCard 不使用 detail 尺寸类。
- 全局 `:focus-visible` 提供 3px focus ring；链接、卡片、筛选、频道、taxonomy 等拥有现有 hover/active 规则；reduced-motion 中仅为关闭平滑滚动和动画使用 `!important`。
- UI 十六进制颜色集中在 `:root` 与虚构封面默认值；18 张封面颜色位于 Mock 数据，是本地 CSS 图形输入，不是另一套 UI 主题。
- 发现与新发行标题、面板、结果和空状态存在相似 CSS，但没有第二个样式文件；响应式选择器覆盖是断点需要。0.2G 应合并相同根因，不能追加更高特异性的单页覆盖。
