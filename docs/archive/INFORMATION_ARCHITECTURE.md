# 信息架构

本文记录 v0.2 已实现的导航、路由、页面顺序和状态职责。所有页面当前只读取完全虚构的
本地 Mock 数据。

## 主导航

普通主导航固定为：

1. 首页
2. 发现专辑
3. 新发行

搜索位于页头右侧，是独立入口，不属于普通主导航列表。全站不显示国内专区、国外专区，
也不把网易云市场频道当作历史专辑地区导航。

## 路由

| 路由 | 页面职责 | 当前主要状态 |
| --- | --- | --- |
| `/` | 专辑发现入口 | 近期发行、高分专辑、按流派探索、随机发现 |
| `/discover` | 统一历史专辑目录 | 筛选、排序、活动条件、空结果、URL 恢复 |
| `/new-releases` | 新发行来源列表 | 市场频道、发行类型、去重、日期排序、空结果 |
| `/search` | 本地专辑搜索 | 初始、有结果、无结果、清空、`q` URL 恢复 |
| `/albums/[slug]` | 单张专辑详情 | 基本信息、禁用收听入口、分类、评分、曲目、来源 |
| not-found | 未知路由或专辑 | 友好 404、返回发现页或首页 |

`/albums/[slug]` 当前从 18 张 Mock 专辑生成 18 条静态详情路由。账号、艺术家详情、
评论、收藏、播放和后台管理路由不属于 v0.2。

## 核心主链路

```text
进入首页
→ 搜索或浏览
→ 使用筛选继续发现
→ 查看专辑详情
→ 未来前往网易云音乐
```

v0.2 的网易云入口仍然禁用，因此最后一步只验证入口位置和语义，不执行外部跳转。

## 全站结构

每个主要页面显式组合 SiteHeader、页面主内容和 SiteFooter。页头提供 skip link、三项
主导航和独立搜索入口；Footer 说明当前内容为本地虚构静态原型。

页面共享 `.page-container` 最大宽度、蓝黑视觉 token、AlbumCard、AlbumGrid 和明确的
focus-visible。首页网格使用 2/3/6 列，发现、新发行和搜索目录网格使用 2/4/6 列。

## 首页顺序

1. SiteHeader
2. Hero：站点定位和浏览提示
3. 近期发行：6 张按发行日期排列的专辑
4. 高分专辑：6 张满足 v0.2 Mock 评分人数门槛的专辑
5. 按流派探索：6 个稳定主流派入口
6. 随机发现：可轮换并进入详情
7. SiteFooter

首页不再展示“最近收录”。`addedAt` 和最近收录排序能力仍保留，但不属于当前首页信息
层级。首页也不包含热度、国内／国外精选或编辑推荐。

## 发现专辑顺序

1. 页面标题和统一目录说明；
2. 主要筛选：年代、发行类型、主流派和排序；
3. 更多筛选：次要流派和描述标签；
4. 活动筛选标签与清除操作；
5. 结果数量；
6. 专辑网格或空结果状态；
7. SiteFooter。

手机端主要筛选使用原生 `details` 默认折叠，活动筛选和清除操作在收起时仍可见。状态
使用 `decade`、`type`、`primaryGenre`、`secondaryGenre`、`descriptor` 和 `sort`
查询参数表达；无效值回退默认状态。

发现页不提供最低评分人数筛选 UI、评分最低排序、完整 RYM 分类树、国家、国内／国外、
语言、国籍、华语／海外历史目录或热度筛选。

## 新发行顺序

1. 页面标题和本地原型说明；
2. `ALL`、`ZH`、`EA`、`JP`、`KR` 市场频道；
3. 发行类型筛选；
4. 频道含义说明；
5. 当前频道名称和结果数量；
6. 按发行日期排列的专辑网格或空结果状态；
7. SiteFooter。

频道和类型使用 `channel`、`type` 查询参数。ALL 对跨频道专辑去重；日期相同时按标题
稳定排序。市场频道只属于来源发现上下文，不代表国家、地区、语言、法域或国籍，也不
转化为全站历史专辑筛选。

## 搜索顺序

1. 页面标题和搜索范围说明；
2. 语义化搜索表单；
3. 无关键词初始状态、结果标题与数量，或无结果状态；
4. 结果 AlbumGrid；
5. SiteFooter。

搜索范围为专辑标题、别名和艺术家名称。`q` 查询参数是唯一状态来源；提交、刷新、清空
和浏览器前进／后退都会从 URL 恢复。结果复用 AlbumCard，点击后进入现有详情路由。

## 专辑详情顺序

1. SiteHeader
2. 面包屑
3. 封面与基本信息
4. 禁用的网易云入口
5. 主流派、次要流派和描述标签
6. RYM 社区评分与评分人数
7. 曲目表
8. 数据来源说明
9. SiteFooter

基本信息包括名称、别名（存在时）、艺术家、发行日期、发行类型、发行公司（存在时）和
曲目数量。分类标签返回发现页现有查询参数。曲目按碟号和曲序排列，并保留必要的曲目
艺术家与时长。无评分显示明确缺失状态；无发行公司不生成空行。

详情页不提供推荐曲目、评论、收藏、用户评分、在线播放、多平台入口或国家、语言、国籍
字段。网易云入口在 v0.2 中使用 `aria-disabled` 且没有真实链接。

## 404 与空状态

- 搜索初始状态解释可搜索字段；
- 搜索、发现和新发行无结果时保留各自产品语义与安全返回操作；
- 未知专辑调用框架 not-found，提供返回发现页和首页的入口；
- 缺 RYM 数据不显示 0 分，缺发行公司不显示空字段；
- 所有操作保持键盘可用和清晰 focus。

## 数据依赖边界

v0.2 页面只消费本地 Mock 数据。未来前台仍应消费已发布读模型，不读取 Cookie，不实时
调用网易云或 RYM，也不根据姓名、文字语言、搜索顺序或市场频道猜测国家和国籍。
