## 采集与拒绝

扩展入口是人工维护的网易云艺人 ID 清单，不采用模糊搜索首条结果。候选通过专辑 ID、艺人 ID、标题、发行年份、类型和曲目数复核；详情和封面只在维护脚本中匿名、串行、限频获取。没有使用登录、Cookie、Token、Authorization、代理、请求头伪装或访问限制绕过。

两条记录未发布：`mysterious-path` 仅 1 首曲目；`a-love-supreme` 的当前固定结果被网易云标记为 Single。二者均不满足允许类型和最低曲目要求。单条失败没有污染已发布快照，请求缓存和原始响应不进入源码包或浏览器资源。

当前仓库没有获准的离线 RYM 分类记录，也没有在本阶段访问 RYM。可靠匹配 0，未匹配 319，歧义 0。因此 319 张专辑只保留人工确认的核心流派，延伸流派和氛围与特征分配均为 0，页面和筛选器隐藏空分类。《在雨后醒来》和《超级孙先生》均只保留 `hip-hop` 核心流派。

## 产品与性能结果

- 首页按“为你推荐、最近收录、核心流派发现、随机发现”组织；
- 发现页只使用实际存在的分类，并提供流派、年代、类型和稳定排序入口；
- 搜索只匹配专辑标题、别名和艺人，支持中文、英文大小写、空白规范化及 URL 恢复；
- 推荐仍是本地确定性函数，排除已保存、喜欢、听过和不适合记录，并把近期浏览年代作为真实多样性信号；
- 详情使用真实本地封面和曲目，外链仅允许匹配 albumId 的 HTTPS 网易云专辑页；
- 个人状态继续版本化、迁移、损坏恢复和目录 ID 对账，不新增账号或云同步。

列表、搜索和推荐消费不含曲目表的 `catalog-index.json`（约 470 KiB）；详情静态生成单独消费 `catalog.json`（约 1.40 MiB）。普通目录页面不会携带 3,312 条完整曲目数据。
