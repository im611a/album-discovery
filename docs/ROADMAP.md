# 路线图

路线图使用显式阶段门。完成一个阶段不会自动授权下一个阶段。

## 0.1 工程与决策基线（当前阶段）

交付范围：

- Next.js、TypeScript、Tailwind、ESLint、Vitest 与 Git 基础工程；
- `AGENTS.md` 和五个项目级 Skills；
- 产品、信息、数据、网易云、RYM、开源研究与路线图文档；
- shadcn/ui 最小配置，不添加未使用组件；
- lint、typecheck、test、build 与 Git 状态检查。

退出条件是上述内容相互一致并通过质量门。0.1 不包含页面开发、数据库、真实
网易云请求、RYM 抓取或部署。

## 0.15 网易云可行性验证（尚未进入）

只有收到明确指令后，才可按 `NETEASE_FEASIBILITY_PLAN.md` 创建隔离实验，
验证匿名目录接口、字段完整性、速率、稳定性和合规边界。

本阶段当前只存在计划；没有创建 `experiments/netease-catalog-spike` 实现，
也没有发起任何网易云请求。验证失败时应返回修改数据策略，而不是绕过限制。

进入条件：0.15 通过且用户明确批准。当前不得安装 Prisma 或接入 PostgreSQL。

- 是否部署仍需独立明确授权。
