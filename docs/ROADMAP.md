# 路线图

路线图使用显式阶段门。完成一个阶段不会自动授权下一个阶段。

## 0.1 工程与决策基线（已完成）

交付范围：

- Next.js、TypeScript、Tailwind、ESLint、Vitest 与 Git 基础工程；
- `AGENTS.md` 和五个项目级 Skills；
- 产品、信息、数据、网易云、RYM、开源研究与路线图文档；
- shadcn/ui 最小配置，不添加未使用组件；
- lint、typecheck、test、build 与 Git 状态检查。

退出条件是上述内容相互一致并通过质量门。0.1 不包含页面开发、数据库、真实
网易云请求、RYM 抓取或部署。

## 0.15 网易云可行性验证（已完成）

0.15A 验证匿名核心目录字段，0.15B 验证地区与市场分类信号。实验报告保留在
`NETEASE_FEASIBILITY_REPORT.md` 和 `NETEASE_REGION_TAXONOMY_REPORT.md`。

结论：核心专辑元数据具备小规模匿名可行性；地区和语种字段不可用；`ZH`、`EA`、
`JP`、`KR` 只能作为新发行请求侧市场频道。实验不证明生产、全量或长期稳定性。

## 0.16 正式产品方案收敛（当前阶段）

- 使用统一“专辑发现”目录，取消国内／国外一级分区。
- 主导航确定为首页、发现专辑、新发行、搜索。
- 新发行可以显示明确标注来源的网易云市场频道，不用于历史专辑地区分类。
- 核心专辑模型不强制包含国家、地区、国籍或语言字段；频道只进入来源发现上下文。
- 更新产品、信息、数据架构、网易云策略和相关项目 Skill。

本阶段只修改文档与 Skill，不开发页面、不接入数据库、不访问上游、不实现正式
Provider。退出条件是指定文档一致、冲突关键词语境正确并通过质量门。

## 0.2 数据契约与持久化决策（未开始）

- 根据 0.16 正式文档冻结网易云适配器契约；
- 选择持久化方案并定义迁移、批次和发布快照；
- 用合成 fixture 验证数据模型，不导入真实 RYM 数据。

进入条件：0.16 完成且用户明确批准。当前不得安装 Prisma 或接入 PostgreSQL。

## 0.3 受控数据导入（未开始）

- 实现服务器端网易云目录批处理；
- 仅从获授权离线文件实现 RYM 导入；
- 建立匹配复核、质量统计和快照发布。

进入条件：数据契约冻结、数据来源与访问方式获得批准。

## 0.4 最小产品界面（未开始）

- 实现四模块首页、发现专辑、新发行、搜索与专辑详情页；
- 只读取已发布快照；
- 完成响应式、可访问性、空状态和错误状态。

不加入用户系统、评论、收藏、用户评分、在线播放、推荐曲目或热度功能。

## 0.5 稳定化与发布评审（未开始）

- 性能、可访问性、数据新鲜度与故障恢复评审；
- 合规、许可证、运行手册和部署方案评审；
- 是否部署仍需独立明确授权。

## 当前停止点

完成 0.16 后必须停止并等待下一条指令，不能自动开始 0.2、页面、数据库、数据导入
或正式 Provider 开发。
