# 专题发现体系

## 路由

| 类型 | 索引 | 详情 |
|---|---|---|
| 核心流派 | `/genres/` | `/genres/core/[slug]/` |
| 相关流派 | `/genres/` 的低权重区域 | `/genres/related/[slug]/` |
| 聆听场景 | `/scenes/` | `/scenes/[slug]/` |
| 年代 | `/decades/` | `/decades/[slug]/` |

只为当前轻量目录索引中至少含一张专辑的 key 生成静态详情页。未知或空 slug 由静态 404 处理。

## 数据规则

- 核心流派使用当前目录人工确认的稳定 key。
- 相关流派只使用可靠离线 RYM Secondary Genres，不从核心流派、场景或描述词推导。
- 聆听场景是本站策展维度，页面明确标注，不声称来自 RYM 或网易云。
- 年代只取合法 `releaseYear`，不使用收录日期。
- 专题索引显示真实数量与最多四张真实封面，不生成介绍、榜单、热度或趋势。

可靠中文名存在时显示“中文（English）”，否则保留英文。数据层和 URL 始终使用稳定英文 key。

## URL、筛选与分页

专题详情支持实际有意义的年代、核心流派、发行类型和排序组合。筛选与排序先作用于专题的完整轻量摘要集合，再按 48 张分页。`page`、`decade`、`genre`、`type`、`sort` 均使用标准查询参数；筛选或排序变化会删除 `page`，非法或越界页码安全回退。

RYM 评分排序把有评分专辑排在前面，无评分专辑按最近收录与标题稳定排序。随机发现由专题种子确定，不使用热度。

## 标签链接

详情页的核心流派、相关流派、聆听场景和年代链接到专题。AlbumCard 最多显示两个核心流派入口；入口与整卡详情链接是相邻的独立交互元素，不产生嵌套链接。专题页提供返回发现和探索的入口。
