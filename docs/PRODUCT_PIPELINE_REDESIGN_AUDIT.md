## 网易云同步管线

命令：

```text
pnpm catalog:sync -- --seed <本地 JSON 或 CSV> --dry-run --limit 10
pnpm catalog:sync -- --seed <本地 JSON 或 CSV> --resume
```

管线支持专辑与艺人种子、去重、固定十项批次、至少两秒请求间隔、单项最多一次重试、原始响应缓存、检查点、resume、结构化失败日志、候选校验和原子发布。401、403、429 或明确风控会停止对应请求；不使用登录、Cookie、Token、私人数据、代理或限制绕过。未变化专辑不请求，已存在封面不下载；新封面下载后生成本地缩略图和详情 WebP。网易云刷新会保留已有可靠 RYM 字段。

小规模验证使用仓库内 10 个已审核 albumId：第一次 dry-run 处理 10 项、识别 10 项未变化、0 失败、0 发布；resume 再次识别全部检查点，0 新增、0 更新、0 发布。该验证没有发出网络请求，因此匿名在线新增同步仍标记为 `PARTIAL`，没有伪造新增专辑数量。

## 可选 RYM 离线增强

命令：

```text
pnpm catalog:enrich:rym -- --input <合法离线 JSON>
pnpm catalog:enrich:rym -- --input <合法离线 JSON> --dry-run
```

输入必须提供数据集名称、来源、获取日期、许可依据、导入字段和可计算的 SHA-256。匹配同时要求标题或登记别名、完整艺人集合、年份、发行类型和唯一候选。只有 `MATCHED` 可以发布评分、评分人数、引用、观测时间、Primary Genres 或 Secondary Genres；非匹配状态不得携带这些字段。当前产品契约拒绝 descriptor 导入。

本轮没有用户提供或仓库已有的合法 RYM 离线数据，因此没有执行真实增强，也没有访问 RYM。当前评分全部为 `null`，相关流派全部为空；目录、推荐和构建不受影响。

## 独立审计结论

在实现完成后重新检查数据所有权、同步与 RYM 边界、索引形状、推荐原因、搜索、个人状态、静态路由、外链、封面产物、敏感信息、依赖和 Git 范围。审计中发现并关闭：

1. RYM 非匹配输入原先未显式拒绝 descriptor 与观测时间；
2. 封面去重分支在未来出现重复二进制时可能先复制、后生成规范文件；
3. 源码打包以所有路径作为命令参数，在 Windows 大目录上会超过命令行上限。

修复后，RYM 导入字段白名单明确拒绝 descriptor，重复封面改为先生成规范文件再复制，源码包改用 tar 文件列表标准输入。对应回归测试已加入。
