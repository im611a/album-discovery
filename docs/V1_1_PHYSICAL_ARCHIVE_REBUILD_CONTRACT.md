## 静态阶段原创体验

1. **槽位索引脊**：每张封套的固定槽位带可读编号和细书脊，解决“封面自由漂浮”的问题；
   出现在环形收藏柜的槽壁上，以纯 CSS 结构实现。
2. **三面包装台**：active 封套同时展示正面、书脊和半开的内袋，解决“封面加阴影”的问题；
   出现在重点专辑展台，全部字段来自本地详情。
3. **档案抽屉接力**：艺人、流派、年代和场景采用不同的抽屉/隔板结构，解决首页后半段同质卡片问题；
   通过共享材质变量和各章节不同几何实现。

前两项及第三项均进入静态实现。
