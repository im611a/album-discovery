# V1.1 内部视觉门

状态：VERIFIED

## 代表范围

- 首页：编辑画廊、九个真实版位、全部后续章节；
- 发现页：筛选、48 张分页与专辑卡片；
- 详情页：`/albums/ok-computer/` 的封面、元数据、分类、评分和曲目；
- 桌面 Header 与 360–390px 移动菜单。

## 证据

Chromium（本机 Edge 通道）在 360×800、390×844、768×1024、1024×768、
1280×800、1440×900、1920×1080 运行静态站点检查。本站像素基准保存在
`tests/e2e/__screenshots__/chromium/`，参考站截图不作为基准。

人工复核确认：

- 蓝黑 token 与宋体栈生效，首页不是等大网格；
- 1440、1920 有大中小封面、显著负空间和可见章节推进；
- 初版 360 首屏只露出一张封面，修正独立双列规则后可见两张；
- 发现页仍能迅速看到筛选、结果数量和双列结果；
- 详情页标题、艺人、日期、类型、外链和操作在首屏可读；
- 所有目标宽度无横向溢出，Header 不遮挡，封面保持链接；
- reduced-motion 下内容完整，console error 与音乐 Provider 请求均为 0。

## 门结论

Blocker 0，Major 0。代表页面可以扩展至全站公共视觉系统。
