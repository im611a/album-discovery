# 产品规格

状态：阶段 0.2C 静态新发行页原型规则，更新于 2026-07-16。

## 产品定位

本项目是一个无需账号的专辑发现站点，帮助用户从近期作品、口碑作品、
新收录作品和随机结果中找到下一张想听的专辑。站点负责整理和解释专辑
信息，不承担音乐播放、社交或个人资料管理。

目标用户希望快速看到专辑封面、创作者、发行信息、曲目、社区评价与风格
标签，然后前往网易云音乐收听。

## 第一版体验

### 视觉方向

第一版采用克制的蓝黑视觉：蓝黑页面与次级背景、深蓝灰卡片、冷蓝交互强调、
冷白主文字和灰蓝辅助文字。专辑封面保留丰富色彩。界面不使用蓝紫渐变、玻璃拟态、
霓虹发光或大面积亮蓝，也不呈现为游戏或科技仪表盘。

### 主导航与统一目录

第一版只使用一个“专辑发现”目录，不按国内、国外、国家、地区或语言市场拆成
多个历史目录。桌面端主导航固定为：

1. **首页**
2. **发现专辑**
3. **新发行**

搜索位于页头右侧，表现为独立的搜索框、按钮或图标入口，不作为普通主导航项。

不设置“国内专区”或“国外专区”，也不使用“华语／海外”作为全站历史专辑分类。
网易云没有提供足以可靠区分中国大陆、香港、台湾、澳门和国外的专辑或艺术家字段，
产品不得从名字、文字语言、搜索位置或频道成员关系猜测地区。

### 首页

首页只包含四个发现模块：

1. **近期发行**：按专辑发行日期展示最近发行的专辑，可使用已同步的网易云新发行数据。
2. **高分专辑**：按 RYM 评分展示口碑较高的专辑，同时展示评分人数；最低
   评分人数门槛在有真实分布后再确定。
3. **最近收录**：按本站首次成功收录时间展示新增目录记录。
4. **随机发现**：从满足基本数据质量要求的专辑中生成可刷新结果。

第一版彻底删除热度排序、热度指数和“正在流行”模块。上述四个模块不得
使用播放量、搜索量或站内行为合成替代热度。

首页不提供国内精选、国外精选或人工每日推荐。

### 发现专辑

第一版默认展示的筛选条件为：

- 发行年份与发行年代；
- 发行类型；
- RYM Primary Genres。

以下条件收纳在“更多筛选”中：

- RYM Secondary Genres；
- RYM Descriptors。

排序方式为：最新发行、最早发行、RYM 评分最高、RYM 评分人数最多。随机发现是
独立的发现动作，不作为结果排序方式；第一版不提供“RYM 评分最低”排序。发现页
不提供国家、国内／国外、中国大陆／香港／台湾／澳门、华语／海外历史专辑或热度筛选。

### 新发行

新发行页可以提供以下网易云市场频道筛选：全部、华语新碟、欧美新碟、日本新碟、
韩国新碟，对应来源参数 `ALL`、`ZH`、`EA`、`JP`、`KR`。

界面必须说明它们是网易云新发行接口的请求侧市场频道，只适用于新发行列表，不是
艺术家国籍、专辑地区、语言或法域，也不能用于全站历史专辑筛选。

新发行页可以组合一个发行类型筛选，并始终按发行日期从新到旧排列；不提供评分、
随机或热度等复杂排序。频道与类型使用稳定 URL 参数保存，历史专辑浏览仍由
`/discover` 承担。

### 搜索

搜索支持专辑名称、专辑别名和艺术家名称，不按国家、地区或语言预先分组结果。

### 专辑详情

详情页提供：

- 专辑封面、专辑名称与别名、艺术家；
- 发行日期、发行类型，以及存在时的发行公司；
- RYM 社区评分与评分人数；
- RYM Primary Genres、Secondary Genres 和 Descriptors；
- 曲目表；
- 唯一的“前往网易云音乐收听”外部入口；
- 数据来源和更新时间。

第一版不展示未经可靠来源确认的国家、地区、艺术家国籍或专辑语言。缺失字段应
隐藏或显示“暂无信息”，不得猜测。

详情页不提供推荐曲目，不嵌入播放器，也不代理音频。

## 数据职责

- 网易云音乐是专辑目录、封面、曲目和唯一收听入口的主要来源。
- RYM 是评分、评分人数、Primary Genres、Secondary Genres 和 Descriptors
  的来源。
- MusicBrainz、Cover Art Archive、ListenBrainz 和 Last.fm 仅可出现在历史
  对比或明确不采用的说明中，不是第一版正式数据来源。
- 前台只读取本站已发布的数据快照，不实时依赖网易云或 RYM。
- 网易云市场频道只作为新发行发现上下文，不是专辑固有字段。

字段级权威关系与匹配规则见 `DATA_ARCHITECTURE.md`。

## 明确不做

第一版不做：

- 登录、注册或任何用户系统；
- 评论、收藏、用户评分或个性化资料；
- 在线播放、音频代理、推荐曲目或歌单管理；
- 多平台收听入口；
- 任何热度功能或“正在流行”展示；
- 国内／国外一级分区、国家筛选或华语／海外历史专辑分类；
- 国内精选、国外精选或人工每日推荐；
- 从非正式来源补齐正式字段；
- 前台实时请求网易云或 RYM。

## 第一版验收原则

- 首页四个模块的语义和排序依据可解释且互不混淆。
- 主导航只包含首页、发现专辑和新发行；搜索作为页头右侧的独立入口。
- 新发行市场频道有明确来源说明，且不会泄漏为历史专辑地区筛选。
- 每张已发布专辑的正式字段均能追溯到网易云或 RYM 及对应导入批次。
- 上游暂时不可用时，前台仍可读取最近一次已发布快照。
- 缺失 RYM 数据时如实显示缺失状态，不以 0 分替代。
- 产品中不存在用户入口、站内播放入口、推荐曲目或热度入口。

## 当前阶段边界

阶段 0.2C 只使用本地虚构 Mock 数据验证新发行市场频道、发行类型、URL 状态、
去重排序与空结果。当前不得发起网易云或 RYM 请求、接入数据库、实现正式 Provider，
或继续开发搜索和专辑详情功能。
