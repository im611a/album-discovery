# 产品规格

状态：v0.2 静态产品原型实施、自动验证、人工验收与最终文档均已完成。本文件随 0.2H
最终文档提交生效；是否已整合到 main，以当前 Git 历史为准。更新于 2026-07-17。

## 产品定位

专辑发现是一个面向中文用户、无需账号的轻量专辑目录。用户可以从首页、筛选目录、
新发行列表或搜索进入专辑详情，了解发行信息、社区评价、分类和曲目，并在未来真实数据
阶段前往网易云音乐。

v0.2 只验证信息架构、页面契约、响应式与交互。当前 18 张专辑、艺术家、评分、分类、
发行信息和曲目全部是完全虚构的本地 Mock 数据；页面不会请求网易云、RYM 或其他音乐
数据源。

## 视觉与导航

界面采用克制的蓝黑视觉：蓝黑背景、深蓝灰卡片、冷蓝交互强调、冷白主文字和灰蓝辅助
文字。专辑封面由本地 CSS 图形生成。界面不使用蓝紫渐变、玻璃拟态、霓虹发光或大面积
亮蓝。

主导航为：

1. 首页
2. 发现专辑
3. 新发行

搜索位于页头右侧，是独立入口，不属于普通主导航列表。第一版使用一个统一专辑目录，
不提供国内专区、国外专区或华语／海外历史专辑分区。

## 首页

首页按以下顺序展示四个模块：

1. **近期发行**：按发行日期从新到旧选择本地专辑。
2. **高分专辑**：按 RYM 原型评分排序，并使用仅供 v0.2 Mock 演示的可配置评分人数门槛。
3. **按流派探索**：从稳定配置进入发现页现有 `primaryGenre` URL 契约，每个入口在当前
   Mock 数据中均有结果。
4. **随机发现**：在本地候选中轮换，并可进入当前专辑详情。

高分人数门槛不是 RYM 官方榜单规则，也不是未来生产默认值。首页不再展示“最近收录”，
但 `addedAt` 数据和最近收录排序能力仍保留，供后续正式数据阶段评估。

首页不包含热度榜、正在流行、国内精选、国外精选、人工每日推荐或编辑推荐。

## 发现专辑

`/discover` 当前支持：

- 发行年代；
- 发行类型；
- RYM Primary Genres（主流派）；
- RYM Secondary Genres（次要流派）；
- RYM Descriptors（描述标签）；
- 最新发行；
- 最早发行；
- RYM 评分最高；
- RYM 评分人数最多；
- URL 参数恢复、单项移除、清除全部与空结果状态；
- 手机端主要筛选默认折叠。

v0.2 不提供最低评分人数筛选 UI、大型流派搜索器、完整 RYM 流派树、RYM 评分最低
排序、热度排序，或任何国家、国内／国外、语言、国籍和华语／海外历史专辑筛选。

## 新发行

`/new-releases` 提供以下市场频道：

| 显示名称 | 稳定值 |
| --- | --- |
| 全部 | `ALL` |
| 华语新碟 | `ZH` |
| 欧美新碟 | `EA` |
| 日本新碟 | `JP` |
| 韩国新碟 | `KR` |

页面还提供发行类型筛选。频道和类型状态写入 URL，无效参数回退默认值；ALL 结果按
专辑去重，最终始终按发行日期从新到旧、标题稳定次序排列。

市场频道只表示专辑通过哪个网易云新发行来源列表被发现，不代表专辑或艺术家的国家、
地区、国籍、语言或法域，也不用于历史专辑筛选。新发行页不提供评分、随机或热度排序。

## 搜索

`/search` 在 18 张本地 Mock 专辑中搜索：

- 专辑标题；
- 专辑别名；
- 艺术家名称。

搜索支持中文和英文、忽略英文大小写、移除关键词首尾空格并进行部分匹配。同一专辑即使
命中多个字段也只出现一次。匹配顺序为：标题完全、别名完全、艺术家完全、标题部分、
别名部分、艺术家部分；同级先按发行日期降序，再按中文标题稳定排序。

关键词使用 `q` URL 参数保存，支持刷新以及浏览器前进和后退。页面包含无关键词初始
状态、搜索结果、无结果状态与清空操作，结果复用现有专辑卡片并进入详情页。

v0.2 不包含拼音搜索、模糊纠错、搜索历史、AI 推荐、艺术家详情页或全文搜索引擎。

## 专辑详情

`/albums/[slug]` 按以下顺序展示：

1. 封面、名称与别名、艺术家、发行日期、发行类型、可选发行公司和曲目数量；
2. 网易云音乐外部入口；
3. RYM 主流派、次要流派和描述标签；
4. RYM 社区评分与评分人数；
5. 曲目表；
6. 数据来源说明。

发行公司缺失时整个字段隐藏。分类标签使用稳定参数返回发现页。曲目支持双碟和多艺术家
署名。无 RYM 数据时显示“暂无 RYM 评分”，不以 0 分替代。

网易云入口在 v0.2 中明确禁用且没有 `href`。详情页不提供推荐曲目、在线播放、评论、
收藏、用户评分、多平台入口或强制长篇介绍。未经可靠来源确认的国家、地区、艺术家国籍
和专辑语言不得展示或猜测。

## Mock 数据边界

- 18 张专辑、艺术家、评分、评分人数、分类、发行公司和曲目全部虚构；
- CSS 封面只用于验证 UI，不代表真实封面；
- Mock 新发行频道关联只用于验证来源上下文和跨频道去重；
- 当前数据不代表真实 RYM 评分或网易云目录；
- Mock 类型是前端 fixture 契约，不应直接迁移为生产数据或数据库表。

## 未来数据职责

- 网易云音乐计划提供专辑目录、封面、曲目和唯一外部收听入口；
- RYM 计划通过用户提供的离线文件提供评分、评分人数、Primary Genres、Secondary
  Genres 和 Descriptors；
- MusicBrainz、Cover Art Archive、ListenBrainz 和 Last.fm 不是第一版正式数据源；
- 前台未来仍只读取本站发布的本地读模型，不实时依赖网易云或 RYM。

具体字段权威关系与来源追踪规则见 [DATA_ARCHITECTURE.md](./DATA_ARCHITECTURE.md)。

## 明确不做

v0.2 不做：

- 登录、注册或其他用户系统；
- 评论、收藏、用户评分或个性化资料；
- 在线播放、音频代理、推荐曲目或歌单；
- 多平台收听入口；
- 热度排名、热度指数或正在流行；
- 国内／国外一级分区、国家、语言或国籍筛选；
- AI 推荐；
- 真实数据同步、数据库、正式 Provider、后台管理或部署。
