# v0.2 静态产品原型：剩余工程执行计划

## 1. 任务目标

v0.2 使用完全虚构的本地 Mock 数据，完成中文专辑发现站点的主要页面体验和稳定页面契约。最终交付必须让用户能够从首页或搜索进入统一专辑目录，使用筛选继续发现，查看完整专辑详情，并看到未来前往网易云音乐的唯一外部入口位置。

本版本验证桌面端与移动端布局、URL 状态、键盘操作、空状态和 18 条静态详情路由，不接入网易云、RYM、数据库、用户系统或正式 Provider。计划只定义 v0.2 的剩余工作；数据库、生产同步、RYM 导入和部署只在路线图中高层引用。

## 2. 项目定位与主链路

网站定位：帮助中文用户发现、浏览和了解完整音乐专辑的轻量目录网站。

核心主链路：

```text
进入首页
→ 搜索或浏览专辑
→ 使用筛选继续发现
→ 查看专辑详情
→ 前往网易云音乐
```

网站不是在线播放器、音乐社区、新闻网站、RYM 镜像、艺术家百科或后台管理系统。

v0.2 必须保留蓝黑视觉方向、首页、发现专辑、新发行、专辑详情、页头右侧搜索入口、RYM 评分和评分人数、主流派/次要流派/描述标签、曲目表、网易云唯一收听入口、URL 参数状态和随机发现。

v0.2 明确不做登录、注册、评论、收藏、用户评分、在线播放、推荐曲目、多平台入口、热度、国内／国外一级分区、国家/国籍/语言筛选、AI 推荐、艺术家详情页、数据库、Prisma、正式 Provider、真实网易云数据或真实 RYM 数据。

## 4. 当前问题

### 产品

- `src/app/search/page.tsx` 仍是占位页，核心主链路缺少搜索能力。
- `src/app/page.tsx` 仍展示“最近收录”，而后续正式收敛决定要求保留数据能力但移除首页展示，以稳定“按流派探索”替换。
- `src/lib/albums.ts` 的 `byHighestRating` 未执行最低评分人数门槛，和首页说明不完全一致。
- `src/components/random-discovery.tsx` 没有进入已有详情页的链接。

### 视觉

- `src/components/albums/album-detail.tsx` 与 `src/app/globals.css` 让大号 RYM 评分先于网易云入口和分类，视觉权重压过主链路。

### 交互

- 搜索没有 `q` 参数、输入、键盘提交、清空、初始状态、无结果状态或 history 恢复。
- 当前测试能验证 URL 纯函数和 `router.push`，不能替代真实浏览器的刷新、前进/后退和三断点验收。
- 响应式、hover、focus、active 与无横向溢出主要依赖人工检查。

### 工程

- DiscoverCatalog 与 NewReleasesCatalog 有相似 URL 导航样板；搜索不得引入第三套状态框架，但也不能在没有共同契约时过度抽象。

### F. 数据和状态流

```text
URLSearchParams → parseSearchQuery / serializeSearchQuery in src/lib/album-search.ts
src/data/albums.mock.ts + parsed q
→ searchAlbums(albums, q) in src/lib/album-search.ts
→ SearchCatalog
→ results.map(result.album)
→ AlbumGrid
→ AlbumCard
→ /albums/[slug]
```

- `q` 是唯一查询参数；读取时 trim，匹配时对英文使用大小写折叠并支持中文/英文部分匹配。
- 写入 `q` 时必须使用 `URLSearchParams` 或等价标准 API 构造查询字符串，不能手工拼接未编码关键词；中文、空格、`&`、`+` 必须正确往返。
- 六级匹配优先级固定为：标题完全、别名完全、艺术家完全、标题部分、别名部分、艺术家部分。
- 同优先级先按 `releaseDate` 从新到旧，再按标题 `zh-CN` 稳定排序。
- 同一专辑即使同时匹配标题、别名和艺术家也最多输出一次；多字段命中时，内部 `matchReason` 必须采用该专辑命中的最高优先级。
- `matchReason` 只用于排序与测试，不出现在普通 UI。
- 表单输入使用本地状态；提交时 trim 后通过标准查询参数 API 生成目标 URL，空值回到 `/search`。
- `useSearchParams()` 变化时同步输入，从而支持刷新和浏览器前进/后退；不得使用全局状态管理。
- 初始无 `q` 显示引导状态；有 `q` 无匹配显示无结果和清空动作；结果显示数量。
