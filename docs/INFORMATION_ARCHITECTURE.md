# 信息架构

本文只定义第一版的信息层级和页面职责，不代表页面已经实现。

## 路由范围

| 路由 | 目的 | 主要内容 |
| --- | --- | --- |
| `/` | 专辑发现入口 | 近期发行、高分专辑、最近收录、随机发现 |
| `/discover` | 统一历史专辑目录 | 年份、年代、发行类型、RYM 分类筛选与排序 |
| `/releases` | 新发行列表 | 网易云市场频道筛选和来源说明 |
| `/search` | 专辑与艺术家搜索 | 专辑名、别名、艺术家名 |
| `/albums/[id]` | 单张专辑事实页 | 基本资料、RYM 丰富信息、曲目、网易云外链 |

账号、个人中心、评论、收藏和播放路由不属于第一版。404 和错误页属于框架级状态，
不扩展产品功能。

## 首页层级

1. 站点标识与一句简短定位。
2. 近期发行：强调发行时间，不表达受欢迎程度。
3. 高分专辑：同时展示 RYM 评分和评分人数，避免只看分数造成误读。
4. 最近收录：强调本站目录更新时间，不暗示发行时间。
5. 随机发现：提供明确刷新动作，结果可在一次请求内保持稳定。

每个模块使用同一精简专辑摘要：封面、专辑名、艺术家、年份，以及仅在该
模块需要时显示的评分或时间信息。点击摘要进入详情页。

首页不得出现“正在流行”、热度榜、国内精选、国外精选或人工每日推荐。

## 发现专辑层级

1. 页面标题和统一目录说明。
2. 筛选：发行年份、发行年代、发行类型、Primary Genres、Secondary Genres、
   Descriptors。
3. 排序：最新发行、最早发行、RYM 评分最高、RYM 评分最低、RYM 评分人数最多、
   随机发现。
4. 结果摘要与分页/继续浏览状态。

不提供国家、国内／国外、中国大陆／香港／台湾／澳门、华语／海外历史专辑或热度
筛选。

## 新发行层级

1. 页面标题和“网易云新发行市场频道”来源说明。
2. 筛选：全部、华语新碟、欧美新碟、日本新碟、韩国新碟。
3. 近期发行专辑结果与数据更新时间。

频道仅对应 `ALL`、`ZH`、`EA`、`JP`、`KR` 请求上下文。页面必须明确它们不是国籍、
法域、语言或正式地区，且不能跳转为全站历史专辑筛选。

## 搜索层级

搜索框接受专辑名称、专辑别名和艺术家名称。结果使用统一专辑摘要，不提供国家或
地区分组，也不通过文字语言猜测分类。

## 专辑详情层级

1. **身份区**：封面、专辑名与别名、艺术家、发行日期、发行类型、存在时的发行公司。
2. **RYM 评价区**：评分、评分人数；无数据时显示“暂无 RYM 数据”。
3. **分类区**：Primary Genres、Secondary Genres、Descriptors 分组展示，
   不把 descriptors 混入流派。
4. **曲目区**：按网易云提供的碟号和曲序排列，仅展示曲目信息。
5. **收听动作**：单一外部按钮，跳转到对应网易云专辑页。
6. **来源区**：字段来源与最后更新时间。

不设置“相似专辑”“猜你喜欢”或推荐曲目区域。
未经可靠来源确认的国家、地区、艺术家国籍和专辑语言不得展示；缺失时隐藏或明确
显示“暂无信息”。

## 导航原则

- 主导航固定为首页、发现专辑、新发行、搜索；详情页提供返回发现上下文的普通导航。
- 不显示国内专区、国外专区，也不把华语／海外作为历史目录入口。
- 网易云收听链接必须标识为外部跳转，不能伪装为站内播放。
- 不显示登录、注册、收藏、评分或评论控件。
- 不为尚未确定的功能预留空导航项。

## 内容状态

| 状态 | 处理 |
| --- | --- |
| 加载 | 使用与目标内容尺寸接近的最小占位，不显示虚假数据 |
| 空结果 | 解释当前模块暂无合格记录，不自动切换为另一排序 |
| 缺封面 | 使用本站静态占位，保留替代文本 |
| 缺 RYM 数据 | 明确标记缺失，隐藏空标签组，不显示 0 分 |
| 上游过期 | 继续展示已发布快照；前台不尝试直连上游补救 |
| 不存在 | 返回明确的专辑不存在状态，不猜测相近 ID |

## 数据依赖边界

所有页面只消费本地发布读模型。页面渲染不得读取 Cookie，不得实时调用
网易云或 RYM，也不得因为快照缺字段而改用其他音乐服务补齐。
