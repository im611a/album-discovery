# 网易云目录可行性验证计划

状态：**0.15A 与 0.15B 已完成；0.16 已采纳产品与数据边界，未进入正式接入。**

实际结果、证据边界和风险见
[NETEASE_FEASIBILITY_REPORT.md](./NETEASE_FEASIBILITY_REPORT.md)。本文件保留阶段门、
问题清单和验证方法，不用计划内容替代实测报告。

地区与市场频道的补充证据见
[NETEASE_REGION_TAXONOMY_REPORT.md](./NETEASE_REGION_TAXONOMY_REPORT.md)。

## 0.16 正式采纳

- 网易云保留为专辑目录、封面、曲目和唯一收听入口的候选来源。
- 专辑与艺术家没有可靠国家、地区、国籍或语言字段；第一版不保存或展示猜测值。
- 第一版取消国内／国外一级目录，也不把华语／海外用于全站历史专辑。
- `ALL`、`ZH`、`EA`、`JP`、`KR` 只作为新发行请求侧市场频道，保存为来源发现上下文。
- 第一版统一目录导航为首页、发现专辑、新发行、搜索。

这些决定只收敛文档，不授权数据库、正式 Provider、页面开发或新的上游请求。

## 0.15A 开始前的证据状态

已确认事实仅来自公开仓库只读研究：存在第三方 Node.js 实现，代码中包含专辑
搜索、新碟、专辑详情、艺术家专辑和曲目详情等模块，并使用 `weapi`/`eapi`
一类上游协议适配。详见 `OPEN_SOURCE_REFERENCES.md`。

当时尚未确认接口当前可用性、允许的项目用途、匿名覆盖率、字段完整性、分页上限、
速率限制、地区差异、Cookie 需求和长期稳定性。公开代码不是实测证据。0.15A 现在
只为其中一部分问题提供了小样本、短时证据，未验证项仍以报告为准。

## 0.15 要回答的问题

1. 不登录、不提供个人 Cookie 时，哪些目录接口类别可稳定返回？
2. 新碟、搜索、艺术家专辑、专辑详情和曲目结果能否组成可追溯的最小目录？
3. 专辑 ID、标题、艺术家、发行日期、封面、曲序和官方专辑链接是否完整？
4. 分页、重复版本、下架、区域差异和缺失字段如何表现？
5. 单并发低频访问下的延迟、错误率、429/风控信号和响应结构变化如何？
6. 访问方式、缓存、封面使用和批量处理是否满足适用条款与合规要求？

## 隔离实验设计（0.15A 已按授权执行）

- 在独立分支中创建最小实验，范围限定为
  `experiments/netease-catalog-spike` 和相关报告文档。
- 只使用合成搜索词和少量公开专辑 ID，不使用真实用户行为数据。
- 从无账号、无个人 Cookie 路径开始；不测试登录、验证码、播放或解锁接口。
- 单并发、固定间隔、有限样本；本次上限为 60 次，实际为 46 次。
- 遇到 401、403、429、验证码、风控提示或异常响应率立即停止。
- 只保存脱敏响应样例、结构摘要、时间、状态码和版本信息，不保存凭据。

## 验证矩阵

| 接口类别 | 最小样本 | 需要记录 | 通过信号 |
| --- | --- | --- | --- |
| 专辑搜索 | 多种中英文标题 | 分页、ID、版本歧义 | 可匿名、结构稳定、能定位专辑 |
| 新碟/近期发行 | 少量分页 | 时间范围、重复、区域参数 | 可解释的候选集合和发行字段 |
| 艺术家专辑 | 少量艺术家 | 分页、合作/合辑行为 | 可补覆盖且不会无限扩张 |
| 专辑详情 | 已知与边界 ID | 标题、艺术家、日期、封面 | 核心字段完整且错误可分类 |
| 曲目详情 | 单碟与多碟样本 | 曲序、碟号、艺术家 | 能稳定形成展示用曲目表 |
| 官方专辑链接 | 上述专辑 | URL 模板与跳转目标 | 指向网易云专辑页且无需本站播放 |

表中的“通过信号”是判据；本次实际结论和限制见报告的能力判定表。

## 证据要求

每次实验必须记录：

- 日期、代码版本、运行环境和网络区域；
- 请求类别、参数类别、节奏和总量；
- 状态码/业务码分布、延迟、重试和停止原因；
- 脱敏样例的字段覆盖率与结构校验结果；
- 是否使用匿名状态，以及是否观察到 Cookie/登录要求；
- 条款与许可证复核结果。

禁止只用“浏览器里能打开”或第三方项目声称支持作为通过证据。

## 实验时使用的决策门

- **通过**：核心目录在无个人账号路径下满足字段、稳定性、节奏和合规要求。
- **有条件通过**：可行但需要代理服务、短期令牌或高维护逆向；必须再次审批
  运维与合规成本，不能自动进入实现。
- **不通过**：依赖个人账号/验证码、持续风控、不可接受条款、字段不足或稳定性
  无法满足。此时回到产品和数据策略决策，不绕过限制。

## 当前结论

0.15A 与 0.15B 的低频匿名冒烟验证已经结束。核心专辑字段具备小规模可行性证据；
地区/语种字段不可用，新发行市场频道只能提供请求侧宽泛分组。0.16 已将这些结果
写入正式产品和数据文档。长期稳定性、规模、分页、合规和生产访问方式仍未确认，
不得据此自动进入 0.2、数据库、正式数据接入或页面开发。
