# V1.1 参考驱动静态艺术救援审计

## 审计范围

本文件记录 `207c461` 静态艺术基线上的内部实现审计、外部参考核验和三原型采用决定。它不是全站重构计划；本轮只交付首页、发现页和专辑详情页三项可独立验收的静态原型。

## 内部实现结论

| 范围 | 保留 | 深化 | 替换 |
| --- | --- | --- | --- |
| 首页 | 真实精选数据、固定槽位、`AlbumCover`、无脚本静态内容 | 单一唱片档案装置、收藏柜槽位、同一轴线上的连续状态 | 分离的四段说明、`STATE`/设备 HUD 文案、封面与唱片和纸张彼此游离的组合 |
| 发现页 | URL 查询契约、组合筛选、排序、分页、活动筛选标签和逐项清除 | 桌面索引面板、移动端抽屉、结果密度和当前条件反馈 | 原生 `details` 加整排 `select` 的工具条式外观 |
| 专辑详情 | 正式数据顺序、个人状态、网易云/RYM 边界、流派与场景、曲目表、相似度算法 | 一体化实体唱片包装、同艺人陈列和真实关系路径 | 松散封面与唱片、普通卡片网格式“继续探索” |

必须继续保持的详情顺序：

1. 元数据
2. 本地状态
3. 网易云
4. RYM
5. 流派
6. 场景
7. 曲目
8. 同艺人
9. 继续探索

## 外部参考核验

### Codrops 3D Book Showcase

- 主来源：<https://tympanus.net/codrops/2013/01/08/3d-book-showcase/>
- 许可证来源：<https://tympanus.net/codrops/licensing/>
- 许可证：MIT（Codrops 下载演示在未另行声明时使用 MIT）。
- 状态：2013 年实验性演示，文章明确提示浏览器兼容和实验性风险；不作为运行时依赖。
- 可采用：六个物理侧面、前封面与封面内侧、背面、书脊和内部页层的 DOM 分层方法。
- 不采用：jQuery、翻页插件、原演示资源、悬停旋转和整套动画。
- 项目适配：把书本结构改造成正方形唱片外套，补充内套、唱片和曲目纸；普通无脚本状态仍展示完整封面与元数据。

### Radix UI Dialog

- 主来源：<https://www.radix-ui.com/primitives/docs/components/dialog>
- 源码与维护状态：<https://github.com/radix-ui/primitives/tree/main/packages/react/dialog>
- 许可证：MIT，版权归 WorkOS；许可证原文位于 <https://github.com/radix-ui/primitives/blob/main/LICENSE>。
- 可采用：模态层、焦点圈定、Escape 关闭、标题与说明的读屏语义、关闭后焦点恢复。
- 不采用：示例视觉、示例图标和任何产品筛选逻辑。
- 项目适配：同一筛选触发器在桌面呈现索引式覆盖层，在移动端呈现底部抽屉；筛选值、URL、排序和分页仍由现有实现负责。

### WAI-ARIA Dialog Pattern

- 规范来源：<https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/>
- 用途：作为键盘和焦点验收基准，不复制实现。
- 验收重点：打开后焦点进入面板、Tab 不逃逸、Escape 关闭、关闭后焦点回到触发器、存在可见关闭按钮和可感知标题。

## 采用决定

本轮只采用两个代码来源：

1. Codrops 的 MIT 物理分层结构，用于首页与详情页共用的唱片包装组件。
2. Radix UI Dialog 的 MIT 可访问交互原语，用于发现页桌面覆盖层和移动端抽屉。

仓库内现有筛选、推荐、相似专辑、静态导出和正式数据契约不由第三方实现替换。外部参考不提供产品数据，不会引入运行时音乐数据请求。

## 三原型文件边界

### A. 首页实体档案装置

- 主要文件：`src/app/page.tsx`、`src/components/editorial/physical-archive-home.tsx`、`src/config/editorial-home.ts`、`src/app/globals.css`
- 可观察结果：普通脚本状态首屏不出现真实封面；向下滚动后同一装置沿单一轴线依次显露收藏柜和三张唱片展台；桌面 5–7 个槽位，移动端 2–3 个槽位。

### B. 发现页

- 主要文件：`src/components/discover/discover-catalog.tsx`、必要的同目录组件与测试、`src/app/globals.css`
- 可观察结果：桌面使用索引式覆盖面板，移动端使用抽屉；保留全部现有 URL、筛选、排序、分页和无脚本结果链接。

### C. 专辑详情与继续探索

- 主要文件：`src/components/albums/album-detail.tsx`、`src/components/albums/continue-exploring.tsx`、共享实体包装组件、相关测试和 `src/app/globals.css`
- 可观察结果：唱片、内套、封面、书脊和曲目纸属于一个包装结构；同艺人和继续探索不再是两个普通卡片网格；关系理由来自现有相似度结果。

## 停止条件

- 外部来源或许可证无法从原始来源确认。
- 必须引入非 Radix 的新第三方依赖。
- 需要重写现有 URL、筛选、推荐或数据契约才能完成视觉结构。
- 出现无法解释的用户工作区变化。
- 低资源串行测试发现 Blocker 或 Major 且无法在三原型范围内修复。
