# 数据架构

本文定义逻辑数据模型、字段权威和数据流。阶段 0.16 不选择 ORM、不创建
数据库，也不把可行性实验输出视为正式目录导入。

## 字段权威矩阵

| 数据 | 正式来源 | 说明 |
| --- | --- | --- |
| 专辑目录与网易云专辑 ID | 网易云音乐 | 作为目录主键来源和去重基础 |
| 专辑名与别名、艺术家、发行日期、发行类型、发行公司 | 网易云音乐 | 保留上游原始值与规范化值；发行公司允许缺失 |
| 封面与曲目 | 网易云音乐 | 封面只保存可追溯引用；曲目保留顺序 |
| 唯一收听入口 | 网易云音乐 | 只链接官方专辑页，不提供站内播放 |
| 评分与评分人数 | RYM | 同一快照一起导入，缺失不置零 |
| Primary Genres | RYM | 有序多值字段 |
| Secondary Genres | RYM | 与 Primary Genres 分开保存 |
| Descriptors | RYM | 描述词，不作为流派层级 |
| 新发行市场频道 | 网易云发现上下文 | 只记录发现入口，不作为专辑地区或国籍 |

MusicBrainz、Cover Art Archive、ListenBrainz 和 Last.fm 不进入正式字段来源
链。它们既不参与第一版补全，也不作为回退源。

## 逻辑实体

### Album

- 站内稳定 ID；
- 唯一网易云专辑 ID；
- 标题与别名、艺术家关系、发行日期、发行类型、可选发行公司；
- 封面引用、曲目关系、网易云收听链接；
- 首次收录时间、最后成功同步时间、发布状态。

第一版核心 Album 不强制包含 `catalog_region`、`region_code`、
`region_confidence`、国家、艺术家国籍或语言字段。它们不是当前可靠事实；未来只有
在引入经过批准且可追溯的可靠来源后，才可作为可选扩展重新评审。

### Artist 与 Track

- Artist 保存网易云艺术家 ID 和展示名；专辑与艺术家为多对多关系并保留顺序。
- Track 保存网易云曲目 ID、碟号、曲序、标题和艺术家关系。
- Track 只用于专辑曲目展示，不包含音频 URL。

### RymEnrichment

- 关联站内专辑 ID；
- 评分、评分人数、快照日期；
- Primary Genres、Secondary Genres、Descriptors 三个独立有序集合；
- 原始记录引用、导入批次和匹配置信度。

### Provenance 与 Batch

- SourceRecord 保存来源、上游标识、获取/导入时间和内容校验和。
- SourceDiscovery 保存发现上下文：`source_market_channel`、
  `source_list_endpoint`、`discovered_at`。
- IngestionBatch 保存任务类型、版本、数量、失败分类与停止原因。
- MatchDecision 保存候选、匹配规则、置信度和人工复核状态。
- PublishedSnapshot 表示前台当前可读取的、通过质量检查的数据版本。

这些是逻辑职责，不规定数据库表的最终拆分方式。

`source_market_channel` 的允许值为 `ALL`、`ZH`、`EA`、`JP`、`KR`。它只表示专辑
通过哪个网易云新发行市场频道被发现，不等于专辑国籍、语言、法域或正式地区。
同一专辑未来可能关联多个 SourceDiscovery 记录，因此该字段不应直接放入核心
Album（或未来物理 `albums` 表）作为地区字段。

## 数据流

```text
获准的上游或离线文件
        ↓
原始记录 / 批次证据
        ↓
规范化与字段校验
        ↓
网易云目录记录 ← 专辑匹配 → RYM 丰富记录
        ↓
质量检查与可追溯性检查
        ↓
不可变发布快照
        ↓
Next.js 前台只读消费
```

采集失败不能直接破坏当前发布快照；重新运行必须幂等，并能从批次记录判断
哪些数据发生变化。

## 专辑匹配原则

1. 网易云专辑 ID 只标识网易云目录，不尝试把 RYM ID 写成同一命名空间。
2. RYM 候选匹配使用规范化标题、主要艺术家、发行年份和版本信息。
3. 精确且无冲突的候选可高置信度接受；多候选、重发版、豪华版、同名专辑
   进入人工复核。
4. 任何匹配都保留规则版本和证据，不以模糊标题覆盖既有结果。

具体导入策略见 `RYM_IMPORT_STRATEGY.md`。

## 发布读模型

前台所需读模型只暴露：专辑摘要、四个首页集合、统一发现目录、新发行频道列表、
搜索结果、专辑详情和数据更新时间。
读模型不暴露上游 Cookie、原始响应、内部失败信息或音频地址，也不在请求时
回源网易云或 RYM。

统一发现目录需要支持发行年份、发行年代、发行类型和 RYM 三类分类字段，以及
发行日期、RYM 评分、评分人数和随机排序所需的可解释输入。国家、地区、语言和
热度不进入第一版筛选读模型。

## 当前未决事项

- 持久化技术与物理表结构留到后续阶段决定；当前不安装 Prisma、不接入
  PostgreSQL。
- 覆盖率、刷新周期、RYM 匹配阈值和高分模块的最低评分人数需要真实数据
  分布后再定。
- 0.15A/0.15B 只提供小规模匿名可行性证据；长期稳定性、合规、分页和生产访问方式
  仍待后续独立决策。
