## 结论与升级点

48/40 的客户端分页能控制 DOM 数量，但当前发现与搜索仍接收完整轻量索引。单索引在 319 张时简单可审计；manifest 的 `upgradeThreshold` 为工程提示而非性能承诺，达到约 2,000 张前应依据真实部署重新测量并转为静态 JSON 分片和路由级按需加载。

合成查询证明纯函数可处理 50k 摘要，不代表 Next.js 能经济地导出 50k 个详情页。当前输出体积随逐专辑、逐艺人和专题页面线性增长；目录进入数千张时应评估按需页面生成或服务器/CDN 数据层。数万张时不建议继续逐条纯静态导出。
