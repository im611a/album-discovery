# V1.1 参考站运动图谱

状态：VERIFIED（有限公开页面观察）

## 边界

- 公开来源：`https://meinhardtaxer.com/`
- 观察日期：2026-07-24。
- 使用本机 Playwright / Edge 通道，只保存有限截图、滚动位置、可见元素矩形和
  `getComputedStyle(...).transform` 结果。
- 证据位于被忽略的
  `.local-data/design-reference/meinhardtaxer-motion-atlas/`。
- 没有保存 HTML、完整 DOM、CSS、JavaScript bundle、字体、图片素材、Logo、
  Cookie、localStorage 或个人信息。
- 本图谱只提炼节奏与空间关系，不作为本站像素坐标或品牌复制来源。

## 实际观察范围

- 视口：1920×1080、1440×900、1280×800、768×1024、390×844、360×800。
- 每个视口记录滚动位置 0、100、200、400、700、1200、2000，共 42 张关键帧。
- 每个视口在滚动 700px 后检查指针位置：左上、右上、中央、左下、右下。
- 六个视口均访问成功，console error 均为 0。

## 已确认事实

1. 页面依赖很长的纵向序列：实测 scrollHeight 从 15,619px（360）到
   23,627px（1920）。
2. 桌面首批视觉对象具有明确大、中、小层级，并通过不对称水平位置和纵向错位制造节奏。
3. 平板与手机不是按比例缩小桌面版位，而是改变可见数量、大小关系和边缘裁切。
4. 从 0 到 2,000px 的分段截图显示对象通过滚动逐步进入视口；静态布局本身承担
   主要叙事，即使不依赖复杂运行时动画仍能读懂。
5. 五个指针位置下，抽查的可见 `img` 计算 transform 均为 `none`。因此没有证据
   可以宣称参考站图片使用指针视差。

## 推导到本站的原则

- 采用：大中小封面层级、长滚动章节、编号、负空间、下一章节露出、移动端重新构图。
- 主动改造：本站使用正方形真实专辑封面、中文宋体编辑层级、真实目录链接与本机状态。
- 本任务要求的指针视差是本站自己的有限交互，不冒充参考站事实；幅度必须小、按需单
  RAF、静止即停，并可被 reduced-motion 完全禁用。
- 本站重点专辑的唱片和活动索引是原创叙事装置，不复制参考站素材或控制方式。

## 明确不采用

- 参考站品牌、文案、字体、图片、源码和具体坐标。
- 依赖裁切才成立的不可读文本、滚动劫持、视频、WebGL 或永久动画。
- 将参考截图纳入本站像素回归。
