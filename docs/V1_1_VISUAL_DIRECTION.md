# V1.1 全站视觉方向

状态：`READY_FOR_HUMAN_REVIEW`

## 一句话方向

把 319 张真实专辑组织成一册会随阅读推进的蓝黑音乐档案：封面进入空间，文字保持安静，
工具页仍准确高效。

## 空间与节奏

- 首页先给出名称、说明和几何唱片标记，普通模式初始不直接铺满封面。
- 九张真实封面随原生滚动按序进入；桌面精细指针提供低幅、不同深度的空间响应。
- 三张重点专辑以 `/01 → /02 → /03` 推进，活动黑胶只在当前章节旋转。
- 全站不复制首页长舞台。详情页采用有限叙事进入，工具页只做轻量标题与结果反馈。
- 手机端是独立自然流，不缩放桌面坐标，不依赖 hover 才能理解信息。

## 内容语法

- 发现与专题使用稳定卡片网格和真实筛选。
- 搜索使用紧凑专辑行与艺人档案行，保留 40 条分页与 URL 状态。
- 艺人索引每人最多一张默认封面；艺人详情使用 2–5 张本地专辑封面而非外部艺人照片。
- 专辑详情让曲目优先于增强分类；网易云入口是明确的编辑型外链，不伪装播放器。
- 404 使用“未找到该档案”，提供首页、发现、搜索三个真实出口。

## 动效语法

Anime.js 4.5.0 是唯一动画引擎，只在局部客户端岛中使用 `createScope`，卸载时
`scope.revert()`。滚动与指针写入只影响 `transform`、`opacity` 和 CSS 变量。
CSS 负责 hover、focus、active 与 reduced-motion。

## 边界

不复制参考站素材，不引入第二动画库，不改目录数据、本机状态 schema、推荐算法、
静态路由或运行时数据边界。`READY_FOR_HUMAN_REVIEW` 不是用户批准。
