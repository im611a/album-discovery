# V1.1 视觉方向

## 一句话方向

把专辑目录组织成一册安静的蓝黑音乐档案：封面承担情绪，宋体承担编辑层级，
工具页承担准确操作。

## 页面语法

- 首页：12 列非对称画布、大中小三级封面、九个固定版位、长滚动章节；
- 工具页：规则容器、横向分隔线、紧凑表单和稳定分页；
- 详情页：大封面与标题并置，后续信息按内容关系排列；
- 手机：不缩放桌面坐标，改用独立双列或单列流；
- 页尾：目录、艺人、专题和本站说明组成档案索引。

## 动效语法

Anime.js 只负责首屏错峰和进入视口的一次性 reveal；hover 与 focus 由 CSS 完成。
动画只改变 opacity/transform，尊重 reduced-motion，截图参数会稳定跳过动画。

## 禁止

播放器拟态、霓虹发光、玻璃拟态、粒子、3D、远程字体、远程图片、无限循环、
大面积圆角卡片和缺乏依据的编辑评价都不属于本方向。
